AI workflow

ai-list Lists every <!--AI--> placeholder in a document as JSON: its name (or null if unnamed), its 1-based line number, and a cheap status —… ai-check Verifies that the content inside each AI placeholder still matches the checksums recorded by the last ai-fix or ai_update call. ai-fix Records content integrity checksums for AI placeholder sections. ai-comments Lists every //AI: inline review-comment line in a document as JSON: its 1-based line number and its text. ai-context-and-update These two MCP tools have no CLI equivalents.

Structure

fix-headings Normalizes heading hierarchy by fixing level skips. shift-headings Shifts all heading levels by a fixed number of levels. number Adds hierarchical numbering to headings. unnumber Removes hierarchical numbering from headings.

Formatting

reflow Reflows paragraph text to a target line width. semantic-line-breaks Splits paragraph text so that each sentence (and major clause) is on its own line. format-tables Reformats every GFM pipe table in a document so its columns are padded to align.

Checking

validate Checks a markdown file for: sum Adds or updates a content checksum in the YAML front-matter of a markdown file. verify Verifies that the checksum stored in a file's YAML front-matter matches the current file content.
